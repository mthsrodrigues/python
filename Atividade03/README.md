# F056 - Classes em C++ para Objetos Físicos

## Exercício 1 - SimpleMET

Implementação da classe SimpleMET para representar a energia transversa faltante.

Compilar:
cd ex1_met
make

Executar:
./testMET

Limpar:
make clean

## Exercício 2 - Track e SimTrack

Implementação das classes Track e SimTrack para representar traços reconstruídos e informação de verdade simulada.

Compilar:
cd ex2_track
make

Executar:
./testTrack

Limpar:
make clean
